Proje Hakkında
Öğrenmeyi optimize etmek amacıyla, "aralıklı tekrar" (spaced repetition) algoritması kullanılarak geliştirilmiş bir test (quiz) uygulamasıdır. Sistem, kullanıcıların zorlandığı soruları daha sık, kolay bulduğu soruları ise daha seyrek aralıklarla karşılarına çıkararak kalıcı öğrenmeyi hedefler. Güçlü ve performanslı veri yönetimi için backend mimarisi PostgreSQL üzerine kurulmuştur.

-----Öne Çıkan Özellikler

Aralıklı Tekrar Algoritması: Öğrenme verimliliğini ve kalıcılığını artıran dinamik soru yönlendirme sistemi.

Java & OOP Mimari: Nesne Yönelimli Programlama prensiplerine tam uyumlu, temiz (clean code) ve sürdürülebilir altyapı.

İlişkisel Veritabanı: PostgreSQL ile optimize edilmiş, performansa dayalı veri şemaları ve yönetimi.

Güçlü Algoritmik Altyapı: Veri yapıları ve algoritma analizleri göz önünde bulundurularak tasarlanmış sistem akışı.

---- Kullanılan Teknolojiler

Backend: Java

Veritabanı: PostgreSQL

Mimari Kavramlar: OOP, Veri Yapıları, Algoritma Analizi, Tasarım Kalıpları (Design Patterns)
